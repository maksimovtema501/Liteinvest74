# Liteinvest74

Статический сайт, публикуется на GitHub Pages.

- `index.html` — сводка Lite-Invest Chelyabinsk.
- [`chronometer/`](chronometer/) — «Хронометр»: ручной хронометраж лыжных гонок
  и биатлона.
- [`planner/`](planner/) — «Планер»: задачи на день и неделю с галочками
  и расписание репетиторства с переносами и напоминаниями; план на сегодня
  выводится виджетом на рабочий стол iPhone.
- [`lingvo/`](lingvo/) — «Лингво»: английский за полгода–год — тест уровня,
  интервальные повторения, грамматика, диктанты, шэдоуинг и говорение
  каждый день.
- [`chess/`](chess/) — «Шахматы»: игра с ботами 250–3200 и с людьми по сети,
  тренер, который оценивает каждый ход, задачи и «Штурм», 20 интерактивных
  лекций, интервальное повторение позиций, тренажёры, дебюты, разбор партий
  движком Stockfish и ИИ-тренер.

«Хронометр», «Планер», «Лингво» и «Шахматы» — офлайн-приложения (PWA): ставятся
на рабочий стол iPhone и Android и работают без интернета.
