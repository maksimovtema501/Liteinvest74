# Хронометр

Приложение для тренера по лыжным гонкам и биатлону: ручная отсечка спортсменов
на точке дистанции с мгновенным показом места и проигрыша, автоматический протокол.

Работает офлайн, ставится на рабочий стол iPhone и Android как обычное приложение
(PWA). Ничего не нужно устанавливать из App Store.

## Установка на iPhone

1. Открыть ссылку приложения **в Safari** (именно Safari, не Chrome).
2. Нажать кнопку «Поделиться» (квадрат со стрелкой вверх).
3. Выбрать **«На экран „Домой“»** → «Добавить».

На рабочем столе появится иконка секундомера. Приложение запускается на весь
экран, без адресной строки, и работает без интернета.

## Установка на Android

Chrome сам предложит «Установить приложение», либо меню ⋮ → «Установить приложение».

## Как пользоваться

**Настройки** — сначала готовим гонку:

- название гонки;
- как считать время — три режима:
  - **по первому** (по умолчанию): раздельный старт, но судья стоит на дистанции
    и момента старта не видит. Отсчёт идёт от первого прошедшего точку, интервал
    старта каждого номера вычитается автоматически, поэтому места считаются по
    чистому времени. «Дать старт» не нужно — время идёт с первой отсечки;
  - **общий старт**: все уходят вместе, время каждого считается от «Дать старт»;
  - **раздельный**: уход по порядку номеров через интервал, судья на старте;
- интервал в секундах для раздельного старта;
- отсечки — точки дистанции; последняя считается финишем. Для гонки по кругам
  достаточно указать их число, названия проставятся сами;
- что делает тап по номеру: «следующий круг» или «выбранная точка»;
- масштаб приложения — крупнее для работы в перчатках;
- участники: сгенерировать номера 1…N, импортировать файл (CSV, TXT, Excel),
  вставить текст протокола или добавить по одному.

Колонки при импорте определяются по заголовкам (*номер*, *фамилия*, *группа*)
либо по порядку: 1-я — номер, 2-я — имя, 3-я — группа. Лимит — 150 участников.

**Хронометраж** — во время гонки:

- «Дать старт» в момент ухода первого номера;
- тап по номеру в сетке = отсечка, телефон вибрирует;
- в режиме кругов каждый следующий тап по тому же номеру пишет следующую
  отсечку: первый тап — первый круг, второй — второй и так далее. Переключать
  точку вручную не нужно. Повтор в первые 5 секунд игнорируется, чтобы
  случайное касание не съело круг. Крестик стирает последний круг;
- сразу после отсечки вверху на 2,5 секунды всплывает сводка: название точки
  и пятёрка лидеров с отставаниями. Окно не ловит касания — отсекать можно
  прямо сквозь него;
- крупная карточка показывает номер, время, место и проигрыш лидеру
  (или «лидер +X» зелёным, если спортсмен вышел вперёд);
- крестик на плитке стирает ошибочную отсечку;
- ручной ввод номера — быстрее при большом числе участников;
- если отсечек несколько, переключатель сверху выбирает текущую точку.

**Гонки** — архив:

- «Новая гонка» с названием — текущая при этом сохраняется целиком, вместе с
  отсечками и протоколом;
- список всех гонок с датой, числом участников и числом финишировавших;
  дата берётся по времени старта, а если гонка не стартовала — по созданию;
- тап по строке открывает гонку: можно вернуться к ней хоть через год,
  посмотреть протокол и выгрузить CSV;
- крестик удаляет гонку, с подтверждением.

**Протокол** — результаты:

- «Зачёт по отсечке» — места и отставания считаются по выбранной точке,
  активная колонка подсвечена;
- «Общий» / «По группам» — сквозной зачёт или разбивка по категориям;
- статусы: **лидер**, **+8.4** (проигрыш), **на трассе** (стартовал, до точки
  не дошёл), **—** (точку не проходил);
- экспорт CSV — на iPhone открывается системное «Поделиться», в остальных
  случаях файл скачивается. Кириллица в Excel читается корректно (BOM);
- **«Завершить и сохранить гонку»** — есть и здесь, и внизу хронометража,
  с подтверждением. Секундомер останавливается на времени финиша, приложение
  открывает итоговый протокол, отсечки блокируются. Гонка остаётся в архиве:
  открыл во вкладке «Гонки» — сразу видишь протокол. Кнопка «Продолжить гонку»
  снимает завершение, если нажали случайно.

## Особенности

- **Данные хранятся только на устройстве** (localStorage), интернет не нужен.
  Хранятся все гонки, а не только текущая.
  Гонка не потеряется, если свернуть приложение или заблокировать экран:
  время считается от абсолютных меток, а не от таймера.
- Экран не гаснет во время гонки, пока приложение открыто (Screen Wake Lock).
- Раздельный старт считает время старта как `t0 + позиция_по_номеру × интервал`,
  то есть предполагает уход строго по порядку номеров через равный интервал.
  Для произвольного стартового протокола нужно хранить индивидуальное время
  старта у каждого спортсмена.
- В режиме «по первому» абсолютное время неизвестно, поэтому за ноль берётся
  лучший результат на точке: лидер показывает 0:00.0, остальные — отставание
  от него. Отрицательных времён не возникает. Отсчёт считается отдельно на
  каждой отсечке, сравнивать времена разных отсечек между собой нельзя.
- Импорт Excel подгружает библиотеку из сети — на морозе без связи сохраняйте
  список заранее или используйте CSV/TXT, они разбираются офлайн.
- Одно устройство = одна точка. Синхронизации нескольких судей нет.

## Разработка

Сборка не нужна — это статические файлы:

```
index.html              всё приложение (разметка, стили, логика)
manifest.webmanifest    описание PWA
sw.js                   service worker, офлайн-кэш
icon-*.png              иконки
assets/make-icons.py    генератор иконок
```

Локальный запуск: `python3 -m http.server` в этой папке, затем открыть
`http://localhost:8000/`.

После изменения файлов поднимите версию кэша `CACHE` в `sw.js`, иначе у
установленных приложений останется старая версия.
