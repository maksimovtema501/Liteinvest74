# Планер

Приложение-планер на телефон: задачи на день и на неделю с галочками и
расписание репетиторства — занятия можно планировать, переносить, отменять
и получать напоминания.

Работает офлайн, ставится на рабочий стол iPhone и Android как обычное
приложение (PWA). Ничего не нужно устанавливать из App Store, регистрация
не нужна.

## Установка на iPhone

1. Открыть ссылку приложения **в Safari** (именно Safari, не Chrome).
2. Нажать кнопку «Поделиться» (квадрат со стрелкой вверх).
3. Выбрать **«На экран „Домой“»** → «Добавить».

На рабочем столе появится иконка календаря с галочкой. Приложение запускается
на весь экран, без адресной строки, и работает без интернета.

## Установка на Android

Chrome сам предложит «Установить приложение», либо меню ⋮ → «Установить приложение».

## Как пользоваться

### День

- сверху — процент выполненного за день и полоса прогресса; когда всё сделано,
  она становится зелёной;
- поле «Новая задача» добавляет задачу в один тап. Если в конце написать время
  («Позвонить маме 18:30»), оно распознается и станет временем задачи;
- тап по квадратику ставит галочку: задача зачёркивается, прогресс пересчитывается,
  телефон коротко вибрирует. Повторный тап снимает галочку;
- тап по тексту задачи открывает карточку: название, дата, время, важность
  (обычная / нужная / важная), повтор, дата окончания повтора, заметка;
- в карточке есть быстрый перенос: «Сегодня», «Завтра», «+1 день», «+1 неделя»;
- стрелки ‹ › и свайп влево-вправо листают дни;
- **Просрочено** — невыполненные задачи прошлых дней; показываются только на
  сегодня, кнопка «Перенести всё на сегодня» разгребает их разом;
- занятия репетиторства на этот день показываются отдельным блоком сверху.

### Неделя

- семь карточек по дням, у каждой свой мини-прогресс и счётчик «сделано / всего»;
- сегодняшний день подсвечен рамкой, прошедшие дни приглушены;
- галочки работают прямо в недельном списке, задачу можно открыть тем же тапом
  по тексту;
- «＋» в шапке дня добавляет задачу сразу на этот день;
- тап по названию дня открывает его в подробном виде «День»;
- занятия видны строкой с временем и учеником.

### Занятия (репетиторство)

Три режима:

- **Неделя** — расписание по дням выбранной недели, сверху сводка: сколько
  занятий, сколько часов и сколько денег выходит за неделю;
- **Ближайшие** — очередь занятий на месяц вперёд, сгруппированная по дням;
- **Ученики** — карточка на каждого ученика: предметы, занятий на этой неделе
  и в этом месяце, сумма за месяц и дата ближайшего занятия.

Занятие заводится кнопкой «Добавить занятие»: ученик, предмет, дата, время,
длительность, стоимость, место или ссылка, заметка. По умолчанию занятие
**еженедельное** — ставится один раз и дальше повторяется каждую неделю в тот же
день; можно указать дату, до которой занимаетесь, или сделать занятие разовым.

Тап по занятию открывает действия:

- **Перенести это занятие** — новая дата и время (или быстро: завтра, через день,
  через неделю). В еженедельной серии переносится только одно занятие, остальные
  остаются на своих местах; перенесённое помечается «перенесено с 14 сентября»
  и его можно вернуть обратно;
- **Отметить проведённым** — занятие становится зелёным и не мешает в списке
  ближайших;
- **Отменить это занятие** — остаётся в расписании зачёркнутым (ученик заболел),
  в счётчики недели и денег не попадает, возвращается одним тапом;
- **Изменить серию** — правит занятие целиком: время, цену, напоминание;
- **Закончить занятия с …** — закрывает серию с этой даты, прошлое остаётся
  в истории;
- **Удалить** — только это занятие или всю серию.

### Напоминания

Во вкладке «Ещё» включаются уведомления и выбирается, за сколько напоминать
по умолчанию: за 10 минут, 15, 30, час, 2 часа или за сутки. У каждого занятия
время напоминания можно поставить своё. Напоминание приходит один раз, при
переносе занятия — приходит заново на новое время.

### Ещё

- «Сохранить копию (файл)» выгружает все задачи и занятия в JSON, «Загрузить
  из файла» — возвращает их (так же переносятся данные на новый телефон);
- «Удалить все данные» стирает всё, с двойным подтверждением.

## Особенности

- **Данные хранятся только на этом устройстве** (localStorage), сервера и
  регистрации нет. Между двумя телефонами данные не синхронизируются —
  для переноса есть файл копии.
- Напоминания показываются, пока приложение открыто или свёрнуто в фоне.
  Push-сервера нет, поэтому если приложение полностью выгружено из памяти,
  уведомление придёт при следующем открытии (и только если с момента, когда
  оно должно было прозвучать, прошло меньше двух часов). На iPhone уведомления
  работают только у приложения, добавленного на экран «Домой».
- Повторяющаяся задача — одна запись; галочка ставится отдельно на каждый день,
  поэтому вчерашняя отметка не закрывает сегодняшнюю. Перенос одного дня из
  серии делает из него отдельную задачу, серия при этом не ломается.
- Неделя всегда начинается с понедельника.

## Разработка

Сборка не нужна — это статические файлы:

```
index.html              всё приложение (разметка, стили, логика)
manifest.webmanifest    описание PWA
sw.js                   service worker, офлайн-кэш
icon-*.png              иконки
assets/make-icons.py    генератор иконок
```

Локальный запуск: `python3 -m http.server` в этой папке, затем открыть
`http://localhost:8000/`.

После изменения файлов поднимите версию кэша `CACHE` в `sw.js`, иначе у
установленных приложений останется старая версия.
