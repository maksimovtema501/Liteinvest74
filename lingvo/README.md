# Лингво

Приложение на телефон для изучения английского: за полгода–год от нуля или
базы до уверенного B1–B2. Каждый день — короткая тренировка по методикам,
которые реально работают, без зубрёжки списков.

Работает офлайн, ставится на рабочий стол iPhone и Android (PWA), регистрация
не нужна.

## Установка

- **iPhone:** открыть ссылку в **Safari** → «Поделиться» → «На экран „Домой“».
- **Android:** Chrome сам предложит «Установить приложение», либо меню ⋮ →
  «Установить приложение».

## Как устроено

### Тест уровня (5–8 минут)

1. **Словарный запас** — отметить знакомые слова из пяти частотных полос.
   Среди них есть выдуманные слова: кто их отмечает, тот угадывает, и оценка
   словаря уменьшается на величину угадывания.
2. **Грамматика** — вопросы подстраиваются под ответы: блоки по 4 вопроса от
   A1 до C1, 3 из 4 верных — уровень выше, иначе стоп. Есть кнопка «Не знаю».
3. **Аудирование** — диктант фраз до уровня на ступень выше грамматики.

Итог — уровень A0–C1, оценка словаря и что человек на этом уровне умеет,
простыми словами. Есть кнопка «Я полный ноль». Тест можно пересдавать раз
в месяц — план подстроится.

### План и прогноз

Выбираются минуты в день (30 / 45 / 60 / 90), срок (6 или 12 месяцев) и время
на погружение (сериалы, подкасты). Прогноз считается честно, по часам, которые
обычно нужны на уровень (A2 ≈ 200 ч, B1 ≈ 400 ч, B2 ≈ 600 ч), и показывает,
сколько минут в день нужно, чтобы взять следующий уровень за этот срок.

### Тренировка дня

Идёт цепочкой, шаг за шагом:

| Шаг | Что делаешь | Методика |
|---|---|---|
| 🧠 Повторение | карточки, которые пора повторить: вспомнить перевод или набрать слово | интервальные повторения (SM-2), активное припоминание |
| ✨ Новые слова | знакомство → выбор перевода → набор по памяти, пачками по 5 | частотность 80/20, чанки |
| 🧩 Грамматика | правило «на пальцах» → выбор формы → сборка/перевод фраз + 2 вопроса по старым темам | interleaving |
| ✍️ Диктант | 5 фраз на слух, разбор по словам | аудирование |
| 🗣 Шэдоуинг | повторить фразу за диктором, микрофон проверяет | шэдоуинг |
| 💬 Говорение | 1–2 минуты речи на тему с опорными фразами | output |

При 30 минутах в день — первые 4 шага, при 45 — 5, при 60+ — все 6.
Тема грамматики засчитывается при 80% верных, иначе повторяется на следующий
день.

### Остальное

- **Слова** — весь словарь с поиском и фильтрами, свои слова, импорт списка
  («слово — перевод», подходит выгрузка из Quizlet / Anki), «Я это знаю».
- **Грамматика** — 28 тем A1–B2 с правилами и тренировкой.
- **Материалы**:
  - 20 встроенных текстов A1–B2: тап по слову — перевод и «в колоду»,
    озвучка фраз, перевод, шэдоуинг и диктант по тексту;
  - подборка для погружения по уровням со ссылками и советом, как
    заниматься: сериалы, YouTube-каналы, подкасты, сайты и инструменты,
    книги. Кнопка «+ мин погружения» сразу засчитывает время в прогресс.
    Ссылки на YouTube ведут на поиск по каналу, на сериалы — на IMDb.
- **Прогресс** — часы занятий и погружения, серия дней, тепловая карта за
  12 недель, дорожная карта по месяцам, прогноз даты следующего уровня по
  реальному темпу, описание методик, настройки.
- **Тренер** — жёсткий (по умолчанию) или мягкий.
- **Профили** — значок в шапке: несколько человек на одном телефоне, у
  каждого свой уровень, слова, прогресс и настройки. Создать, выбрать,
  переименовать, удалить.

## Особенности

- Данные хранятся только на устройстве (localStorage), у каждого профиля
  отдельно. Для переноса — «Сохранить копию (файл)» / «Загрузить из файла»
  (копия делается для текущего профиля). Прогресс из версии без профилей
  автоматически переезжает в профиль «Я».
- Озвучка — голосами телефона (Web Speech API), голос и скорость меняются
  в настройках.
- Распознавание речи работает в Chrome / Android и в Safari на iOS 14.5+.
  Где его нет, шэдоуинг и говорение идут без проверки — повторяешь сам.
- Время занятий считается только активное: если минуту ничего не нажимать,
  счётчик стоит.
- Встроенный словарь — ~550 самых частотных слов A1–B2, 49 разговорных фраз
  и 35 фразовых глаголов. Дальше словарь растёт за счёт своих слов: из текстов
  (тап по слову), импорта и того, что встречаешь в сериалах.

## Разработка

Сборка не нужна — это статические файлы:

```
index.html              приложение (разметка, стили, логика)
words.js                словарь по уровням и слова для теста
course.js               грамматика, тексты, материалы, темы для говорения, тест, методики
manifest.webmanifest    описание PWA
sw.js                   service worker, офлайн-кэш
icon-*.png              иконки
assets/make-icons.py    генератор иконок
```

Локальный запуск: `python3 -m http.server` в этой папке, затем открыть
`http://localhost:8000/`.

После изменения файлов поднимите версию кэша `CACHE` в `sw.js`, иначе у
установленных приложений останется старая версия.
