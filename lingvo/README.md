# Лингво

Приложение на телефон для изучения английского: за полгода–год от нуля или
базы до уверенного B1–B2. Каждый день — короткая тренировка по методикам,
которые реально работают, без зубрёжки списков.

Работает офлайн, ставится на рабочий стол iPhone и Android (PWA), регистрация
не нужна.

## Установка

- **iPhone:** открыть ссылку в **Safari** → «Поделиться» → «На экран „Домой“».
- **Android:** Chrome сам предложит «Установить приложение», либо меню ⋮ →
  «Установить приложение».

## Как устроено

### Тест уровня (5–8 минут)

1. **Словарный запас** — отметить знакомые слова из пяти частотных полос.
   Среди них есть выдуманные слова: кто их отмечает, тот угадывает, и оценка
   словаря уменьшается на величину угадывания.
2. **Грамматика** — вопросы подстраиваются под ответы: блоки по 4 вопроса от
   A1 до C1, 3 из 4 верных — уровень выше, иначе стоп. Есть кнопка «Не знаю».
3. **Аудирование** — диктант фраз до уровня на ступень выше грамматики.

Итог — уровень A0–C1, оценка словаря и что человек на этом уровне умеет,
простыми словами. Есть кнопка «Я полный ноль». Тест можно пересдавать раз
в месяц — план подстроится.

### План и прогноз

Выбираются минуты в день (30 / 45 / 60 / 90), срок (6 или 12 месяцев) и время
на погружение (сериалы, подкасты). Прогноз считается честно, по часам, которые
обычно нужны на уровень (A2 ≈ 200 ч, B1 ≈ 400 ч, B2 ≈ 600 ч), и показывает,
сколько минут в день нужно, чтобы взять следующий уровень за этот срок.

### Тренировка дня

Идёт цепочкой, шаг за шагом:

| Шаг | Что делаешь | Методика |
|---|---|---|
| 🧠 Повторение | карточки, которые пора повторить: вспомнить перевод или набрать слово | интервальные повторения (FSRS), активное припоминание |
| 🔧 Работа над ошибками | слова из журнала ошибок по 3 ступеням (появляется, когда есть ошибки) | исправление ошибок, прицельная практика |
| ↩️ Повтор грамматики | пройденные темы, у которых подошёл срок, и вопросы, где ошибался (появляется по сроку) | интервальные повторения для правил |
| ✨ Новые слова | угадать значение → перевод и пример → выбор перевода → набор по памяти, пачками по 5, темы вперемешку | претест, частотность 80/20, чанки |
| 🧩 Грамматика | правило «на пальцах» → выбор формы → сборка/перевод фраз + 2 вопроса по старым темам | interleaving |
| ✍️ Диктант | 5 фраз на слух, разбор по словам | аудирование |
| 🗣 Шэдоуинг | повторить фразу за диктором, микрофон проверяет | шэдоуинг |
| 💬 Говорение | 1–2 минуты речи на тему с опорными фразами | output |

При 30 минутах в день — первые 4 шага, при 45 — 5, при 60+ — все 6.
«Работа над ошибками» и «Повтор грамматики» добавляются сразу после
повторения, когда есть что исправлять или повторять: сначала старое
и ошибки, потом новое.
В повторении карточки четырёх видов вперемешку: «вспомни перевод»
(английское → русское), набор слова по-английски и два дополнительных
режима — «вспомни по-английски» (русское и ситуация → английское) и «вставь
слово во фразу» (пример с пропуском, слово нужно поставить в правильной форме:
arrive → arrived). Дополнительные режимы выключаются в настройках
(«Доп. режимы повторения») — тогда повторение работает как раньше.

Тема грамматики засчитывается при 80% верных, иначе повторяется на следующий
день. Освоенная тема возвращается на повтор через 1 → 3 → 7 → 14 → 30 → 60
дней: 80% и выше — следующий повтор позже, меньше — завтра снова. В повтор
первыми идут вопросы, где были ошибки.

### Ступени слова

Каждое слово проходит ступени по интервалу повторения:
🆕 новое → 🌱 знакомлюсь (до 2 дней) → 🌿 учу (2–6 дней) → 🌳 закрепляю
(1–3 недели) → ✅ знаю (3+ недели) → 🏆 выучено (2+ месяца). Слова,
отмеченные «Уже знаю», но не проверенные, идут отдельно (❔) и не считаются
выученными, пока не ответишь на них в проверке. Ступень видна в списке слов
и в карточке слова.

### Журнал ошибок

Каждая ошибка — в повторении, проверке, марафоне, заучивании и грамматике —
попадает в журнал. Ошибка **исправлена**, когда на этот же вопрос ответишь
верно **в два разных дня после ошибки** (●●): так проверяется долгая память,
а не то, что держится в голове сразу после подсказки. Тренировка в день
ошибки помогает, но засчитывается со следующего дня. Новая ошибка снова
открывает запись. Статусы: 🔴 открыта, 🟡 исправляется (1 из 2), 🟢 исправлена.
Журнал открывается из «Прогресса», вкладок «Слова» и «Грамматика» и карточки
«Трудные слова»; из него можно сразу заучивать слова или повторять
грамматику с ошибками. Старые забытые слова и ошибки марафона переносятся
в журнал автоматически.

### Методики и исследования

Что внедрено и на чём основано. Всё, что меняет поведение, выключается
в «Прогресс» → «Методики — переключатели».

| Методика | Как устроено в приложении | Исследования |
|---|---|---|
| Интервальные повторения | расписание строит **FSRS-5** (алгоритм из Anki, параметры по умолчанию): модель «стабильность — трудность — вероятность вспомнить», учитывает реальный перерыв (пропуски не ломают график). Цель — помнить 90% к повторению (можно 85% или 95%). Забытое слово возвращается завтра, но не с нуля. Старые карточки переводятся автоматически: стабильность ≈ прежнему интервалу. Классический SM-2 — в настройках | Cepeda и др. 2006 (обзор 317 экспериментов); Ye и др. 2022 (FSRS) |
| Проверка себя вместо перечитывания | набор слова, выбор, вставка во фразу, вспомнить по русскому | Roediger & Karpicke 2006 |
| Претест | новое слово сначала без перевода: угадай по слову и примеру | Kornell, Hays & Bjork 2009; Potts & Shanks 2014 |
| Похожие слова — не вместе | новые слова одного уровня идут вперемешку по темам, соседние по списку (mother/father, hot/cold) — в разных пачках | Tinkham 1993, 1997; Waring 1997; Nation 2000 |
| Проверка «Уже знаю» | слово засчитывается выученным, только если через несколько карточек сам напишешь его; знакомое слово не съедает дневную норму — вместо него дают следующее | Koriat & Bjork 2005; Dunlosky & Rawson 2012 (иллюзия знания) |
| Слово в разных контекстах | фраза с пропуском — то из примера, то из текстов, книг и примеров других слов (слова A2+ с одним значением) | Bolger и др. 2008; Johns, Dye & Jones 2016 |
| Замечать свои ошибки | в набранных ответах — побуквенный разбор: что перепутал, пропустил, лишнее; перестановка соседних букв считается опечаткой | Schmidt 1990 (гипотеза замечания) |
| 95–98% знакомых слов | у каждого текста — процент знакомых слов (📗 98%+ / 📘 95–97% / 📙 90–94% / 📕 <90%), незнакомые можно выучить перед чтением | Hu & Nation 2000; Laufer & Ravenhorst-Kalovski 2010 |
| Перемешивание | в грамматике — «🔀 Смешанная практика» по всем пройденным темам | Rohrer & Taylor 2007; Nakata & Suzuki 2019 |
| Вывод и вовлечённость | в «Говорении» — слова дня с отметкой, какие ты использовал; ИИ-собеседник вплетает слова, которые ты учишь | Swain 1995; Laufer & Hulstijn 2001 |
| Сон | новое и забытое слово повторяется на следующий день | Mazza и др. 2016 |
| План «когда и где» | на «Сегодня» — свой план «если …, то …» и «⚡ 5 минут» на день без времени | Gollwitzer & Sheeran 2006; Lally и др. 2010 |
| Умная норма | если повторений накопилось много, новых слов сегодня вдвое меньше | — |

### Остальное

- **Слова** — весь словарь с поиском и фильтрами (в том числе 🔧 — слова
  с ошибками), ступень у каждого слова, свои слова, импорт списка
  («слово — перевод», подходит выгрузка из Quizlet / Anki), «Я это знаю».
- **🔥 Заучивание трудных** — отдельная тренировка для слов, которые не
  запоминаются: забытые в повторении, ошибки марафона и слова в обучении.
  Пачка 5 / 7 / 10 слов; каждое нужно ответить правильно 3 раза по ступеням
  (узнать перевод → выбрать английское или вставить во фразу → написать
  самому), между ступенями слово уходит на 3–6 карточек назад; ошибка
  возвращает слово на первую ступень, а после двух ошибок — снова на
  карточку «Запомни». К слову можно записать свою подсказку-ассоциацию 💡 —
  она показывается везде, где есть пример слова. «🎧 Слушать по кругу» —
  озвучка трудных слов плейлистом (английское — русское — пример), можно
  слушать в дороге. Карточка «Трудные слова» есть и на экране «Сегодня».
  Расписание повторений заучивание не меняет.
- **✅ Проверить выученные** — проверка в любой момент, не дожидаясь срока
  повторения: выученные слова (интервал 3+ недели), отмеченные «Уже знаю»,
  повторённые раньше срока или вся колода; 20 / 50 / 100 / все. Вопросы
  разные: выбор перевода, написать по-английски, вставить слово во фразу.
  Отвечает приложение, а не самооценка. Расписание повторений не меняется;
  забытые слова в конце одной кнопкой возвращаются в повторение.
- **🏁 Марафон слов** — быстрый прогон с выбором перевода из 4 вариантов
  в обе стороны: по всем словам, по уровню, по одной из 23 тем (еда, работа
  и деньги, путешествия, чувства, связки для речи, фразовые глаголы…) или
  «Работа над ошибками». Забег на 20 / 30 / 50 / 100 слов или все сразу;
  сначала идут непроверенные слова. У каждой темы видно, сколько слов
  знаешь. Ошибки в конце одной кнопкой уходят в повторение.
- **Грамматика** — 28 тем A1–B2 с правилами и тренировкой: в каждой теме
  40 вопросов трёх видов — выбрать форму (16), вписать форму самому (10)
  и перевести фразу (14, с допустимыми вариантами перевода), всего 1120.
  Каждый раз берутся вопросы, которые ты видел реже и давнее остальных, —
  повтор не превращается в заучивание ответов. Проверка в грамматике строже,
  чем в словах: опечатку прощаем, а пропущенное окончание (-s, -ed, -ing…) —
  нет. Повтор пройденных тем по интервалам и «🔀 Смешанная практика» по всем
  пройденным темам.
- **Медиа**:
  - 20 встроенных текстов A1–B2: тап по слову — перевод и «в колоду»,
    озвучка фраз, перевод, шэдоуинг и диктант по тексту;
  - у каждого текста — процент знакомых слов, в читалке — список незнакомых
    слов и кнопка «Выучить перед чтением» (до 10 главных слов);
  - «📚 Чтение» — 48 текстов A1–B2 для чтения и перевода с фильтром по
    видам: 📖 рассказы (20), 📝 выжимки известных книг (10: «Маленький
    принц», «Старик и море», «Ромео и Джульетта», «Алхимик», «Атомные
    привычки», «Преступление и наказание», «1984», «7 навыков», «Sapiens»,
    «Думай медленно… решай быстро» — сюжет или суть и главная мысль),
    📰 статьи (12) и 💬 диалоги (6: врач, ресторан, аренда, жалоба в отеле,
    разговор на работе, собеседование);
  - «✍️ Перевод» в читалке для любого текста: EN→RU — переводишь фразу сам
    (письменно или в уме), сверяешься с эталоном и оцениваешь себя;
    RU→EN — пишешь по-английски, совпавшие с эталоном слова подсвечиваются.
    В конце — точность, а непонятые фразы можно добавить в «Мои слова»;
  - «📕 Книги» — 6 книг классики в адаптированном пересказе под уровень
    (Эзоп, Уайльд, О. Генри, Кэрролл, Конан Дойл, Джек Лондон; 17 глав).
    Перевод по запросу: фраза — кнопкой «перевод», слово — тапом (каждое слово
    книги переводится: основной словарь, словарь книги, служебные слова).
    «📒 Слова главы» — трудные слова главы, любые или все сразу можно взять
    в обучение; переход к следующей главе;
  - «❝ Цитаты» — любую фразу из текста или книги можно сохранить кнопкой ❝;
    плюс 19 известных цитат и пословиц с переводом; из цитат можно отправить
    фразу в обучение;
  - подборка для погружения по уровням со ссылками и советом, как
    заниматься: сериалы, YouTube-каналы, подкасты, сайты и инструменты,
    книги. Кнопка «+ мин погружения» сразу засчитывает время в прогресс.
    Ссылки на YouTube ведут на поиск по каналу, на сериалы — на IMDb.
- **Прогресс** — «📘 Как устроено обучение» (коротко вся методика), часы
  занятий и погружения, слова «знаю» (3+ недели), ошибки в работе
  и исправленные, серия дней; слова по ступеням; итог недели (минуты, дни,
  новые слова, ошибки сделано / исправлено, темы грамматики); календарь
  занятий за 12 недель (квадратик — день, колонка — неделя, строки Пн–Вс;
  цвет — минуты занятий и погружения: 0 / 1–9 / 10–29 / 30–59 / 60+, тап —
  подробности дня); средний темп — по дням с начала занятий (до 14 дней);
  дорожная карта по месяцам с «план против факта» по часам; описание методик,
  настройки.
- **💬 Диалог с ИИ** — живой разговор на английском с Claude: 13 сценариев
  (свободный разговор, знакомство, кафе, магазин, отель, аэропорт, как пройти,
  врач, small talk, фильмы, собеседование, спор, тренировка текущей темы
  грамматики). ИИ говорит на уровне профиля, после каждой твоей реплики
  показывает исправления, даёт перевод своей реплики и два варианта ответа;
  тап по слову — перевод, озвучка ответов, ввод голосом. В конце исправления
  можно добавить в «Мои слова». 6 реплик за день засчитывают шаг «Говорение».
- **Тренер** — жёсткий (по умолчанию) или мягкий.
- **Профили** — значок в шапке: несколько человек на одном телефоне, у
  каждого свой уровень, слова, прогресс и настройки. Создать, выбрать,
  переименовать, удалить.

## Особенности

- Данные хранятся только на устройстве (localStorage), у каждого профиля
  отдельно. Для переноса — «Сохранить копию (файл)» / «Загрузить из файла»
  (копия делается для текущего профиля). Прогресс из версии без профилей
  автоматически переезжает в профиль «Я».
- **☁️ Копия на GitHub** («Прогресс» → «Копия на GitHub»): раз в неделю при
  открытии приложения все профили сохраняются в секретный gist пользователя
  (файл `lingvo-backup.json`, у gist'а хранится история версий). Нужен токен
  GitHub только с правом `gist` — по ссылке из приложения галочка уже стоит.
  Токен хранится только на устройстве и в копию не попадает. На новом телефоне
  после ввода токена приложение находит копию и предлагает её загрузить;
  после восстановления можно вернуть прежние данные. Если данных стало вдвое
  меньше, чем в прошлой копии, автоматическая копия старую не перезаписывает.
- Озвучка — голосами телефона (Web Speech API), голос и скорость меняются
  в настройках.
- Распознавание речи работает в Chrome / Android и в Safari на iOS 14.5+.
  Где его нет, шэдоуинг и говорение идут без проверки — повторяешь сам.
- Время занятий считается только активное: если минуту ничего не нажимать,
  счётчик стоит.
- Встроенный словарь — ~3330 слов и выражений: ~3140 слов A1–B2 (A1 ≈ 460,
  A2 ≈ 710, B1 ≈ 1370, B2 ≈ 600), ~110 разговорных фраз и ~90 фразовых
  глаголов, у каждого — пример с переводом. Новые слова идут по уровням:
  сначала весь A1, потом A2 и т. д.; внутри уровня темы чередуются. Дальше словарь растёт за счёт своих
  слов: из текстов (тап по слову), импорта и того, что встречаешь в сериалах.

## Диалог с ИИ: ключ API

У приложения нет сервера, поэтому для диалога нужен свой ключ Anthropic API:
console.anthropic.com → пополнить баланс (Billing) → API Keys → Create Key →
вставить во вкладке «Диалог». Ключ хранится только в localStorage этого
устройства и отправляется только в api.anthropic.com. Одна реплика стоит
около цента. Модель — Claude Opus 5.5 с низким уровнем рассуждений (быстро
и дёшево); при отказе модели запрос автоматически уходит на запасную модель
(`fallbacks: "default"`).

```
books.js                книги (пересказы классики) и известные цитаты
topics.js               темы словаря для марафона
manifest.webmanifest    описание PWA
sw.js                   service worker, офлайн-кэш
icon-*.png              иконки
assets/make-icons.py    генератор иконок
vendor/anthropic-sdk.mjs  официальный SDK Anthropic, собранный в один файл
```

SDK пересобирается так (в пустой папке):

```
npm i @anthropic-ai/sdk esbuild
echo 'export { default } from "@anthropic-ai/sdk";' > entry.mjs
npx esbuild entry.mjs --bundle --format=esm --platform=browser --minify --outfile=anthropic-sdk.mjs
```

Локальный запуск: `python3 -m http.server` в этой папке, затем открыть
`http://localhost:8000/`.

После изменения файлов поднимите версию кэша `CACHE` в `sw.js`, иначе у
установленных приложений останется старая версия.
